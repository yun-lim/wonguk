# 사주봄

절입 기준 사주 명식. 생년월일은 브라우저에서만 계산합니다.
모바일 Safari / Chrome에서 바로 쓰는 웹 앱입니다. Expo Go가 필요 없습니다.
표시 이름은 사주봄입니다.

## 경로
- / 홈 (카드, 저장 명식)
- /input 입력 후 localStorage 저장
- /reports 리포트
- /pay 요금 (wonguk_once 990, wonguk_monthly 9900/30일, 가상 결제)
- /settings 설정
- /manse 무료 만세력 계산기
